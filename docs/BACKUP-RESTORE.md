# 备份与恢复

## 备份范围

- `.data/shanhai-db.json`
- `.data/uploads/`
- 部署版本号和 `.env` 配置快照

## 频率与保留

- 生产建议：每日全量备份，每小时增量或快照。
- RPO：生产待定，建议不超过 1 小时。
- RTO：生产待定，建议不超过 4 小时。

## 恢复步骤

1. 停止服务。
2. 备份当前损坏数据目录以便审计。
3. 恢复目标时间点的 `shanhai-db.json` 和 `uploads/`。
4. 启动服务。
5. 运行恢复验证。

## 恢复验证

- `GET /api/health`
- 登录测试账号
- 打开我的云端档案
- 打开公开日志
- 抽查上传图片 URL

## 生产待替换项

- 备份目标位置
- 加密密钥管理
- RPO/RTO 签字确认
- 灾备演练记录
